# Wallet Frontend

Vue 3 + TypeScript + Quasar

## Стек

- **Framework**: Vue 3 (Composition API)
- **Language**: TypeScript
- **UI**: Quasar Framework
- **Build**: Vite

## Структура

```
frontend/
├── src/
│   ├── assets/
│   ├── boot/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   ├── router/
│   ├── stores/
│   └── utils/
├── public/
├── package.json
├── quasar.config.ts
├── tsconfig.json
└── Dockerfile
```

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```
