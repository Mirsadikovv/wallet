# review

Проверь все изменённые файлы на соответствие стайл-гайдам проекта.

## Что проверять

Для Go файлов (`backend/`):
- Именование: пакеты, типы, методы, переменные по таблице из CLAUDE_STYLE_BACKEND.md
- Структура: handler / service / dto / model разделены, нет смешивания
- Паттерны: interface + приватная реализация, анонимные блоки `{}`
- Swagger godoc на каждом публичном хендлере
- DTO: теги `json` + `validate`, аннотация `// @Name`
- Запреты: нет `panic`, нет глобальных переменных, нет `Select("*")`, нет `interface{}`/`any`, нет бизнес-логики в хендлерах

Для Vue файлов (`frontend/`):
- Только `<script setup lang="ts">`, только Composition API
- Структура модуля: pages / service / routes / components
- Типизация: нет `any`, все DTO из types

## Формат вывода

Для каждого нарушения:
```
❌ [файл:строка] — описание нарушения
   Как исправить: ...
```

Если нарушений нет:
```
✅ Всё соответствует стайл-гайду
```
